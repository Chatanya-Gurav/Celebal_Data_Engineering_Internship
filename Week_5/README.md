# Week 5 - Apache Spark Data Cleaning and Transformations

## Objective

The objective of this assignment is to learn the fundamentals of Apache Spark and perform data cleaning and transformation tasks using PySpark DataFrames. The assignment demonstrates common Spark operations such as filtering, grouping, handling null values, removing duplicates, schema transformation, and aggregation.

---

## Technologies Used

- Apache Spark (PySpark)
- Python
- Databricks Free Edition

---

## Concepts Covered

- Apache Spark vs MapReduce
- In-Memory Computing
- Spark DataFrames
- Removing Duplicate Records
- Filtering Data
- GroupBy Operations
- Aggregate Functions
- Handling Null Values
- DataFrame Immutability
- Shuffle Operations
- Timestamp Conversion
- Data Cleaning Pipeline

---

## Tasks Performed

- Compared Apache Spark with MapReduce.
- Explained the benefits of In-Memory Computing.
- Removed duplicate records using `dropDuplicates()`.
- Filtered records based on conditions.
- Calculated average values using `groupBy()` and `agg()`.
- Replaced null values using `.na.fill()`.
- Counted records using aggregation functions.
- Applied filtering with multiple conditions.
- Converted string values to `TimestampType`.
- Removed invalid records from the dataset.
- Calculated minimum, maximum, and average values.
- Implemented a complete Spark data processing pipeline.
